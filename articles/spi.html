SPI: Serial Peripheral Interface

SPI is a high-speed, synchronous, full-duplex communication protocol used for SD cards, LCDs, and sensors.

The 4-Wire Interface:

  • SCK: Serial Clock (Generated by Master).
  • MOSI: Master Out Slave In.
  • MISO: Master In Slave Out.
  • CS/SS: Chip Select (Active Low).

SPI is much faster than I2C because it uses a dedicated select line for each device instead of an addressing system.
